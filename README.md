# llama_webui
 лёгкий веб-лаунчер для llama.cpp в одном файле. Сам находит и устанавливает Python и llama.cpp, сканирует диски в поисках .gguf-моделей, читает их метаданные, подбирает контекст и слои на GPU под ваше железо и запускает локальный чат в стиле ChatGPT одной кнопкой. Без зависимостей и установки
